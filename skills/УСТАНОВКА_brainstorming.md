# Как установить навык brainstorming

**Что это:** личный навык «обсуждение перед работой» (вопросы по одному, пересказ, 2–3 подхода, задание на одобрение). Это русская урезанная версия навыка brainstorming из obra/superpowers (лицензия MIT).
**Файлы:** `brainstorming.zip` — архив для загрузки; внутри папка `brainstorming/` с `SKILL.md` и `LICENSE`.

## В claude.ai (веб, приложение, Claude Code в облаке)

1. Скачайте `brainstorming.zip`. **Не распаковывайте** — загружается сам архив. В архиве должна лежать папка `brainstorming/`, а не отдельные файлы.
2. Откройте claude.ai → **Настройки (Settings)** → раздел **Возможности / Capabilities** (в некоторых версиях — **Features**).
3. Проверьте, что включено **выполнение кода / Code execution** — без него свои навыки недоступны.
4. В блоке **Skills** нажмите **Upload skill** (загрузить навык) и выберите `brainstorming.zip`.
5. Включите переключатель у навыка **brainstorming**.
6. Проверка: в новом чате напишите «давай обсудим …» — Claude должен начать с одного вопроса, а не с готового решения.

Свои навыки доступны на тарифах Pro, Max, Team и Enterprise. Навык личный: он работает только у вас и не виден другим людям. Названия пунктов меню иногда меняются — если не нашли, ищите «Skills» в настройках или в справке Claude.

## В Claude Code на своём компьютере (терминал)

Навыки claude.ai туда не переносятся, их ставят отдельно:

```bash
mkdir -p ~/.claude/skills && unzip brainstorming.zip -d ~/.claude/skills/
```

Навык подхватится при следующем запуске Claude Code.

## Как вызвать

Навык включается сам, когда вы просите обсудить, продумать или спланировать большую работу. Можно и явно: «используй навык brainstorming».
