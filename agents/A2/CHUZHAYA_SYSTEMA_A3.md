## 1. Общие правила измерения

Одни правила для всех вариантов. Без них цифры разных вариантов не сравнить.

**Источник цифр**
- Исходник варианта (`zoning_*.js`) и собранная страница.
- `node tools/shot.js <абс. путь к html> <папка> 0,1,2,3,4` — самопроверка, заполнение этажей, суммы по группам табл. 26, снимки.
- `node tools/rooms.js <абс. путь к html>` — выгрузка блоков (этаж, зона, ключ, название, группа, площадь, u, v). Расстояния и глубины считаю по этой геометрии.
- Каждый этаж смотреть на снимке глазами.

**Площади**
- Полезная = брутто × 0,88.
- В программу идёт только помещение, которое нарисовано на плане. «Внутри гардероба», «в ядре» без своего блока — 0.
- **Аванзал** засчитывается только как площадь у выдачи и входов в залы сверх транзитной полосы коридора 2,4 м (допущение). Кольцевой или сквозной коридор целиком — не аванзал (А1, А-2).

**Люди на этаже** (п. 5.3.2.15 СН РК 3.02-07)
- Залы — по **брутто** площади (с запасом, как у А1) и нормам табл. 26: учебные 2,4; научные 3,0; групповые 2,2; аудиовизуальные и редкие 5,0 м² на место; абонемент 1,8.
- Лекционный зал — 150. Буфет — по числу мест, если не указано — площадь / 1,6 (допущение).
- Открытый доступ — 1 человек на 30 м² брутто (допущение; совпадает с 26 чел. в отчётах 2К).
- Персонал — 15 на этаж 2–4, по факту на 1 этаже и в подвале (допущение).
- Коэффициент 1,25 не применяю: залы с регламентированным числом мест (как у коллеги, 02 п. 3.2).

**Двери**
- Если двери не показаны, считаю: одна дверь в середине стороны помещения, выходящей в коридор; у помещений больше 50 человек — две двери в концах этой стороны.
- Если вариант пишет двери в `w` или `NOTES`, беру их.

**Расстояния**
- По оси коридора, ломаной, от двери помещения до двери ЛК.
- Внутри зала — от дальней точки до двери, по прямой × 1,2 (допущение на мебель).

**Связность и зоны**
- Два блока коридоров или холлов, которые касаются друг друга по линии ≥ 1 м, считаются **соединёнными**, если вариант прямо не написал «стена», «турникет», «дверь по пропуску».
- Помещение соединено только с тем коридором или холлом, куда выходит его дверь.

**Стороны света**
- Сектор по нормали фасада, 8 румбов ± 22,5°.
- Фасады библиотеки: ЮЮВ 154,5° (сектор ЮВ), ВСВ 64,5° (СВ), С (С), **ЗСЗ 287,5° (З)**, **ЗЮЗ 244,5° (ЮЗ)**.
- «Запад» по п. 4.4.10.9 — фасады ЗСЗ и ЗЮЗ.

**Источник света для коридора** (пп. 4.3.3.1, 3.13)
- Окно в торце коридора или в световом кармане шириной ≥ 2,0 м (допущение).
- Остеклённая дверь ЛК ≥ 1,2 м, если сама ЛК с окном.
- Атриум с фонарём — **только на 4 этаже** (под фонарём). На 1–3 этажах не засчитываю: свет сверху через 3 этажа за противопожарным стеклом слабый. Это мой выбор, строже, чем в 2К.

## 3. Баллы

Обозначение **lin(x; a → 0, b → max)** — баллы растут линейно от 0 при x = a до максимума при x = b, за пределами — 0 или максимум.

Если критерий к варианту неприменим (например, атриума нет), он получает **полный балл**: нет проёма — нет проблемы.

## 5. Итог и сравнение

**Шаг 1. Допуск.** Проверить Г1–Г11.
- Всё «да» → вариант **допущен**.
- Хоть одно «нет» → **не принят**. В итоге пишем, какие условия не прошли.

**Шаг 2. Баллы.** Сложить Э + Т + С + Р + Д + П + М, максимум 100. Баллы округлять до 0,5.

**Шаг 3. Порог эвакуации.** Если Э < 20 из 30, вариант **не принят**, даже если допуск пройден: эвакуация впритык по всем пунктам — тоже провал.

**Шаг 4. Оценка словами** (только для принятых):

| Баллы | Оценка |
|---|---|
| ≥ 85 | отлично |
| 70–84,5 | хорошо |
| 55–69,5 | удовлетворительно |
| < 55 | слабо — принят, но много править |

**Шаг 5. Сравнение вариантов.**
1. Принятые — выше всех непринятых.
2. Среди принятых — по сумме баллов.
3. Разница меньше 3 баллов — ничья; её решает больший балл Э, затем Д, затем Т.
4. Среди непринятых — сначала меньше проваленных условий, потом больше баллов.

**Форма записи результата**

```
Вариант: …
Допуск: Г1 ✓ · Г2 ✓ (71,4 %) · … · Г11 ✗ (до лифта 75 м)  → не принят / допущен
Баллы: Э 22 · Т 10 · С 11 · Р 9 · Д 8 · П 4 · М 3 = 67 / 100
Итог: …; главные потери: …
```

По каждому критерию в отчёте — цифра, место (этаж, оси) и балл.
